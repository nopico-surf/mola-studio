# Mola Studio

Editor de animação por presets para anúncios de Facebook e Instagram, direto no navegador.

## Rodar

```
npx serve .
```

Depois abra http://localhost:3000 no Chrome ou no Edge. Também dá para abrir o `index.html` direto.

## O que tem

- 8 roteiros prontos
- 20 presets de texto e 15 presets de logo, botão e imagem
- Logo escrito letra a letra (SVG ou PNG com fundo transparente)
- Logo que se desenha e logo montado por partes (SVG)
- Google Fonts pelo nome e upload de fonte própria
- Formatos 1:1, 4:5 e 9:16
- Exportação em MP4

Os detalhes técnicos estão no `CLAUDE.md`.
